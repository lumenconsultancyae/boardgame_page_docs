# Boardgame Page — Documentation & E2E Test Suite (`boardgame_page_docs`)

Companion documentation, Product & Software Design Documents (PRD/SDD), architecture diagrams, rule flowcharts, Docker Compose stack, and Behaviour-Driven Development (BDD) end-to-end test suite for [`lumenconsultancyae/Boardgame-page`](https://github.com/lumenconsultancyae/Boardgame-page).

## Scope

- **Product & Architecture Specifications (`docs/`)**:
  - Product Requirements Document (PRD) and Software Design Document (SDD)
  - Data models for board games, play sessions, visual rule summaries/diagrams, WhatsApp share templates, and UAE boardgame events
  - User guides and rule-diagram authoring conventions
- **Deployment & Stack Configuration**:
  - Containerized local/preview stack orchestration
- **BDD End-to-End Verification (`features/`)**:
  - Gherkin feature specifications and browser E2E step definitions covering game tracking, visual rule diagrams/graphs, WhatsApp message formatting/sharing, and UAE boardgame event discovery
